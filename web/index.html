c6simc6

x86-64 emulator compiled from C6, running in WebAssembly

固件与网络

下拉选内置固件，或选本地 .bin；选完点「启动」。

网络代理（wasm 真上网，可选）

桥接网关 = 浏览器连本机的 ws_slip_proxy.js（一般不用改）； 上游代理 = 网关/NAT 从哪出网，留空直连。

高级：桥接网关地址（默认 ws://127.0.0.1:8787）

未连接（可选：只有 guest 要上外网才需要；本机先跑 node tools/ws_slip_proxy.js）

空闲

串口（终端）

点一下终端后直接输入；Ctrl-C 送 guest，滚轮回看历史。
